## 📁 محتويات المستودع (The 6 Templates)

### 1. 🥐 مخبز وباتيسري فاخر (`01-bakery-patisserie`)
- **النشاط المستهدف:** المخابز، محلات التورت والحلويات، ومحلات الكرواسون والباتيسري.
- **أبرز الخصائص:**
  - هيرو سكشن بصري راقٍ يبرز التخمير الطبيعي وجودة الزبدة الفرنسية.
  - منيو تفاعلي مصنف (كرواسون، تورت، ساوردو، ماكرون، بوكسات جمعات).
  - كروت منتجات بمعاينة سريعة (Quick View) للحساسية والمكونات.
  - سلة مشتريات منزلقة (Cart Drawer) تحسب التوصيل وتنشئ رسالة طلب مفصلة عبر WhatsApp.

### 2. ☕ كافيه ومحمصة مختصة (`02-cafe-specialty-coffee`)
- **النشاط المستهدف:** الكافيهات، مقاهي القهوة المختصة (Specialty Coffee)، والمحامص.
- **أبرز الخصائص:**
  - تركيز على أجواء المكان وبيئة المذاكرة والعمل الهادئة وسرعة الواي فاي.
  - منيو تقطير يدوي (V60 & Chemex)، كولد برو، وإسبريسو، وحبوب بن منزلية.
  - نموذج حجز طاولة وجلسة عمل مرسل مباشرة إلى WhatsApp.

### 3. 🥩 مطعم ومشويات فاخرة (`03-restaurant-dining`)
- **النشاط المستهدف:** المطاعم العائلية، قصور الطهي، ومطاعم المشويات والباستا الإيطالية.
- **أبرز الخصائص:**
  - استعراض أطباق الشيف المميزة (ستيك، ريش ضاني، باستا الكمأة).
  - شريط روابط تطبيقات التوصيل (طلبات، المنيوز، هنقرستيشن).
  - نظام استعراض الفروع المتعددة وحجز الطاولات (تراس أو صالة داخلية).

### 4. 💈 صالون حلاقة ورعاية شخصية (`04-barbershop-salon`)
- **النشاط المستهدف:** صالونات الحلاقة، مراكز العناية الرجالية، وصالونات التجميل.
- **أبرز الخصائص:**
  - قائمة أسعار مفصلة بالوقت والمدة لكل خدمة وباقات العريس VIP.
  - استعراض فريق كبار المصففين وخبراتهم.
  - نظام حجز موعد إلكتروني يصدر تذكرة موعد مرسلة إلى WhatsApp.

### 5. ⚡ جيم ونادي لياقة بدنية (`05-fitness-gym`)
- **النشاط المستهدف:** صالات الجيم، استوديوهات اللياقة البدنية والكروس فيت.
- **أبرز الخصائص:**
  - نموذج طلب **يوم تجربة مجاني (Free 1-Day Pass)** مع فحص InBody لتحويل الزوار لعملاء.
  - مقارنة باقات الاشتراكات (شهري، 3 شهور، سنوي).
  - استعراض البرامج التدريبية، كادر المدربين، وأسئلة شائعة تفاعلية (FAQ).

### 6. 🏢 شركات وخدمات مؤسسية (`06-small-business-services`)
- **النشاط المستهدف:** شركات الصيانة، المقاولات، شبكات المراقبة، أو مكاتب الاستشارات.
- **أبرز الخصائص:**
  - شبكة خدمات تفصيلية ومخطط مراحل العمل المعتمد (Process Roadmap).
  - سابقة أعمال بدراسات حالة حقيقية (Case Studies) وأثر المشاريع.
  - نموذج طلب عرض سعر ودراسة فنية فورية (Quote Request).

## ⚡ كيف تخصص أي قالب لعميلك الجديد في 5 دقائق؟
كل قالب معزول ومنظم ويحتوي على ملف إعدادات `js/data.js`:
```javascript
const CONFIG = {
  brand: {
    nameAr: "اسم نشاط العميل",
    sloganAr: "شعار العميل"
  },
  contact: {
    whatsapp: "201146945584", // رقم واتساب العميل
    addressAr: "عنوان الفرع",
    currency: "ج.م"
  },
  products: [ /* أصناف المنيو أو الخدمات والأسعار */ ]
};
```
بمجرد تعديل هذا الملف، يتم تحديث كامل الموقع ورسائل الواتساب تلقائياً دون الحاجة لتعديل أكواد HTML أو CSS.
